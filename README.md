# 🚚 ERPNext Commercial Fleet & Fuel Logistics Manager

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-Fleet-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An enterprise **Fleet & Fuel Logistics Audit Engine** for **ERPNext Vehicle Asset Management**. Tracks odometer progressions, driver trip dispatches, fuel expenses, and features an **AI / Statistical anomaly detector** to catch fuel theft and engine efficiency degradation.

---

## ⚡ Highlights
- 🚛 **Vehicle Asset Tracking**: Registration, odometer progression, and fuel type.
- ⛽ **Fuel Efficiency & Anomaly Detection**: Automatic calculation of actual vs expected Km/L with leakage / theft alerts.
- 🧪 **Pytest Coverage**: Unit tests included.
